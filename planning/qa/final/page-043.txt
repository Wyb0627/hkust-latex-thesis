3.4.2 Contextual Type Representation Learning
The auxiliary task trains a type representation at a masked position. During training, KGLink
constructs two versions of the processed table. The ground-truth version places the annotated
type label before the candidate types in each target column. The masked version replaces that
label with [MASK]. Both versions retain the column values and candidate-type context. En-
coding the two sequences produces contextual representations for the true type and its masked
counterpart.
