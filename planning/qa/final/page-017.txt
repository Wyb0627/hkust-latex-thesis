The available information determines each retrieval decision. KGLink uses table content and
linked descriptions, with a masked type position at inference. GORAG uses the support exam-
ples and index updates available before the current prediction. AGRAG selects from a fixed
corpus graph for each query. MGRAG progressively extracts query-related facts from ranked
multimodalchunks.
