\section{Motivation}
\label{sec:introduction:motivation}
Language-model pipelines use text, table cells, and images as evidence for prediction or generation. The usefulness of that context depends on which evidence was selected and how its parts relate to one another. A table column may contain names while omitting the occupations needed to identify its semantic type. A classification query may refer to a label introduced after the initial index was constructed. An answer may depend on facts distributed across passages. A multimodal question may express a relationship that corresponds to several facts in the evidence. These settings require decisions about evidence before the model produces its prediction.

This thesis studies explicit structure as a means of making those decisions. A knowledge graph connects an entity to descriptions and relations beyond a table. A task graph connects keywords to labels and can be updated as classification proceeds. An evidence graph supports the selection of connected facts for text generation. A query graph specifies relationships to be matched against multimodal evidence. The central question is how these structures should participate in the computation that supplies context to a language model.

The first setting is column type annotation. Consider a column of people accompanied only by birth and death dates. A model that encodes the table can use the dates as context, but the table may not identify a common occupation. Linking the names to a knowledge graph can supply that information. Conversely, the knowledge graph may associate a person with several valid types, while a dataset expects a particular label vocabulary. KGLink combines external graph information with a pre-trained language model and supervision from the annotation task~\cite{kglink-publication}. The structure supplies evidence; the task determines the label to predict.

The second setting concerns dynamic few-shot text classification. A label set can grow over rounds, with only a few examples available for each label. The retrieval index must represent the available supervision and provide candidates for the current text. Adding every observed word uniformly does not distinguish useful associations from incidental ones. Returning a fixed number of semantically similar passages also leaves the candidate label decision implicit. GORAG constructs and updates weighted keyword--label relations and retrieves labels through connections among query keywords~\cite{gorag-paper}.

The third setting concerns textual question answering and generation. A system can retrieve individually relevant chunks without telling the generator how their facts connect. An answer requiring a summary may also need more information than an economical path between query anchors contains. AGRAG constructs a text evidence graph, scores nodes by query-dependent influence, assigns semantic costs to edges, and selects a connected subgraph. Its hybrid passage retriever supplies additional contextual material~\cite{agrag-paper}. The generator receives both the selected relational structure and text.

The fourth setting introduces multimodal evidence. Images and text can describe the same event with different levels of detail. A direct relation in a question may correspond to a path through several entities in the evidence graph. A query-independent graph can also omit details relevant to a particular question. MGRAG builds an evidence graph incrementally for the query, uses path-based semantic matching to identify corresponding evidence, and incorporates graph features when selecting cached states for recomputation~\cite{mgrag-paper}. Structure influences both retrieval and the processing of the retrieved context.

The common question is how explicit relationships should constrain the evidence used for a task. KGLink selects descriptions for a supervised representation; GORAG selects labels from an evolving index; AGRAG selects connected facts and source context; and MGRAG matches query relations and allocates computation over the selected evidence. Across these studies, the thesis examines where structure is obtained, when it is adapted, and which downstream decision it controls.

\section{Research Scope and Structural Augmentation}
\label{sec:introduction:scope}
\subsection{Evidence, structure, and model roles}
In this thesis, structural augmentation means using explicit relationships among evidence items in a language-model pipeline. The items include entities, types, keywords, labels, passages, and query components. The relationships include knowledge-graph edges, keyword--label associations, passage-to-entity links, and paths that express a query requirement. The term describes where structure participates in the pipeline; the concrete representation is defined separately for each study.

There are three distinctions that organize the scope. First, a graph representation and a learned representation serve different purposes. A graph records named items and their connections. An embedding supplies a learned similarity or a contextual feature. The methods combine these representations in different ways. KGLink serializes graph-derived information for a table encoder. GORAG uses a weighted graph for candidate selection. AGRAG combines node scores and edge costs during evidence retrieval. MGRAG compares the semantics of paths and uses graph features in context computation.

Second, external evidence and supervision have different roles. The knowledge graph in KGLink supplies descriptions that need not appear in a table. Column labels supervise the prediction task. In GORAG, a small labeled training set supplies initial keyword--label associations, while predictions can contribute to online indexing according to the round protocol. In AGRAG and MGRAG, source documents supply the evidence from which graphs are constructed. The experiments specify the information available to each method.

Third, the language models perform different computations. KGLink fine-tunes a pre-trained encoder for column annotation, with a contextual representation objective. The later studies use generative language models for selected extraction, filtering, classification, or answer-generation operations. The thesis therefore includes supervised encoder-based annotation and retrieval-augmented generation.

\subsection{Reasoning through task-specific evidence}
The thesis uses reasoning in relation to the evaluated tasks. In annotation, the model uses table content and external type information to assign a semantic label. In dynamic classification, retrieval selects candidate labels appropriate to the current text and available index. In textual QA, the method supplies connected facts and passages for generating an answer. In multimodal QA, semantic paths relate query requirements to evidence expressed across modalities.

The graph operations are observable components of these pipelines. They select, connect, and present evidence. The resulting task metrics evaluate predictions and generated answers under specified conditions. This makes the interface between structural computation and language-model output the object of study. It also determines the appropriate evidence for each contribution: annotation accuracy and F1, classification results across rounds, task-specific QA measures, and context-serving costs.

The four studies have separate implementations and evaluation settings. Their common argument concerns how explicit relationships can organize knowledge and guide evidence use. The chapters progress through external knowledge, online indexing, connected textual evidence, and query-aware multimodal evidence. Each chapter states the particular mechanism it develops.

A related study on hyper-relational knowledge graphs examines information preservation during structural representation. It distinguishes qualifier information from graph reception and develops FormerGNN in response. This published work appears as a separate section in the background chapter. Its role is to inform the analysis of what a structural representation retains. The experiments concern knowledge-graph embedding rather than language-model augmentation.

\subsection{The evidence interface as a design choice}
The methods can also be understood by asking what information is available at each decision point. Before prediction, KGLink observes the table and linked knowledge but uses a masked type position in the inference sequence. GORAG observes the supervision available in a round and the graph state produced by earlier permitted updates. AGRAG observes the indexed corpus and the current query. MGRAG observes ranked multimodal chunks and progressively extracts facts relevant to its query graph. These information boundaries determine which structural operations are possible.

\section{Research Questions}
\label{sec:introduction:questions}
\subsection{RQ1: External knowledge for table understanding}
The first research question asks how graph-derived information and a pre-trained language model can be combined when a table lacks informative context and the graph's type vocabulary differs from the annotation task. The input consists of a table, an external knowledge graph, and labeled columns from the target task. The output is a semantic type for each target column.

Two difficulties motivate the question. Knowledge-graph linking can return multiple candidate descriptions at different granularities. The target task may require a different abstraction from a graph's available types. Meanwhile, a table encoder can only directly read the content in its input sequence. Surrounding dates or numeric values may provide little evidence about an entity's occupation or role. The method must expose external information while learning how it relates to the task's labels.

KGLink answers the question through cell linking, cross-column neighborhood filtering, row selection, candidate-type construction, and graph-derived feature sequences. These components supply evidence to the table encoder. Contextual masked-type representation training relates that evidence to the target annotation vocabulary. Chapter~\ref{ch:kglink} explains the method and reports the SemTab and VizNet experiments, ablations, no-linkage cases, and efficiency evidence.

\subsection{RQ2: Evidence maintenance under evolving labels}
The second question asks how a retrieval index can maintain task-specific relationships and select relevant labels as a few-shot classification problem evolves. The input includes the examples and labels available at the current round, an existing graph index, and an unseen text. The output is a label prediction and the prescribed index update for subsequent processing.

An evolving label set changes the meaning of evidence retrieval. A candidate must belong to the task's available labels, and the graph must incorporate new supervision without rebuilding its whole representation for every prediction. Within a round, predicted information can affect later queries if the method performs online indexing. Its timing and use of predicted labels therefore belong to the experimental protocol.

GORAG answers this question through weighted keyword--label indexing, terminal-based connected retrieval, and online updates after classification. Its candidate set is selected for the current input rather than specified only by a fixed retrieval count. Chapter~\ref{ch:gorag} describes the round and shot settings, the retrieval construction, and the CAD, WOS, and IFS-Rel results. The chapter also examines the cost of indexing and retrieval and the effect of the proposed components.

\subsection{RQ3: Connected evidence for textual generation}
The third question asks how to select evidence that reflects both its relevance to a query and the connections among its facts. The input is a text corpus and a query whose answer can involve several information items. The output includes an evidence subgraph, passage context, and the generated answer.

A graph-ranking score identifies relevant nodes but does not by itself specify an evidence structure. Conversely, a small structure connecting query anchors may omit additional facts needed for a summary. The system must also account for information that remains in the original text after graph extraction. These requirements motivate a combination of graph selection and passage retrieval.

AGRAG answers the question by constructing a graph with statistically selected entities, extracted relations, passage nodes, and synonym links. Query-mapped facts condition the influence scores; semantic similarity supplies edge costs. The method constructs an initial terminal-connecting structure and expands it according to the reported cost-score rule. A hybrid dense and BM25 channel supplies additional passages. Chapter~\ref{ch:agrag} evaluates these choices across textual QA tasks and classification, retaining the distinct meanings of their metrics.

\subsection{RQ4: Semantic matching and computation over multimodal evidence}
The fourth question asks how to construct and match evidence for a multimodal query when the query and evidence graphs express related information through different topologies, and how that structure can guide context recomputation. The input includes a multimodal corpus, a query, and the model states available for reuse. The output is a matched evidence subgraph and an answer generated under the selected recomputation policy.

A query can contain unknown entities, represented by semantically meaningful placeholders. Evidence may express the requested relation through intermediate entities. The relevant details can also depend on the question posed about an image. These conditions make both the construction of the graph and the matching operation query-dependent. Once selected evidence enters the generator, tokens associated with connected events supply information about which computations to refresh.

MGRAG answers the question through caption-based coarse ranking, incremental query-aware graph construction, and path-based semantic subgraph matching. It then combines query attention, graph-sequence attention, and graph topological features to score tokens for selective KV recomputation. Chapter~\ref{ch:mgrag} reports QA results on MMQA and six MRAMG subsets, comparisons of matching methods, component ablations, and cache quality--cost measurements.

\section{Contributions and Evidence}
\label{sec:introduction:contributions}
The thesis makes four core contributions corresponding to these questions. Each contribution combines a specific structural operation with a language-model task and a published evaluation. Table~\ref{tab:introduction:questions} identifies where the method and evidence are developed. 

\begin{enumerate}
\item \textbf{Knowledge-enriched column representations.} KGLink selects graph-derived evidence using table relationships and integrates that evidence with a pre-trained table encoder. Its contextual representation task connects the graph information to the annotation labels.
\item \textbf{Online structured label retrieval.} GORAG maintains weighted associations between keywords and labels and uses a connected retrieval procedure to generate input-specific candidate labels. Its online indexing incorporates information according to the dynamic classification protocol.
\item \textbf{Influence-aware connected evidence selection.} AGRAG combines statistical entity selection, query-conditioned influence, semantic edge costs, an expanded evidence subgraph, and hybrid passage retrieval.
\item \textbf{Query-aware multimodal matching and recomputation.} MGRAG incrementally constructs evidence graphs for individual queries, matches query relations to semantic paths, and uses graph information in selective KV recomputation.
\end{enumerate}

The published measurements provide quantitative answers to these research questions. On VizNet, KGLink obtains a weighted F1 of 96.07 compared with 95.06 for Doduo, using the percentage scale of the annotation experiment. In GORAG's fourth WOS round, accuracy with ten support examples per label is 0.4929 using Qwen2.5-7B; the one-shot result in the same round is 0.4420. AGRAG obtains Medical contextual-summarization coverage of 0.690 and accuracy of 0.604 with Qwen2.5-14B-Instruct. Its hybrid-retrieval ablation reduces coverage in that task to 0.420, linking the answer's information coverage to the passage channel. MGRAG reaches MMQA accuracy of 0.7442 with Qwen2.5-VL-7B-Instruct. The associated serving comparison reports 4.3 hours for MGRAG and 8.8 hours for vLLM with HippoRAG2. These experiments measure the complete prediction or generation pipeline, while the ablations examine changes to particular components. The research chapters develop the experimental controls and method comparisons behind these measurements, connecting the structural decisions to annotation, classification, answer coverage, and context-processing cost.

The accompanying hyper-relational study contributes a separate analysis of structural information preservation and the FormerGNN design. It provides a representation-level perspective on the thesis theme. The background chapter identifies it explicitly as the author's published research and distinguishes its link-prediction evidence from the downstream language-model evaluations.

The author led the research presented in this thesis under the supervision of Prof. Lei Chen. The work benefited from discussions and collaboration with Dr. Haoyang Li, Dr. Hao Xin, and Dr. Shimin Di. Each research chapter identifies its coauthored publication source.
